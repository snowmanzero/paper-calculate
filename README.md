# 纸张价格计算器

微信小程序 · 印刷纸张成本计算

## 功能

- 输入吨价或令价 + 克重，算出大度、正度、自定义尺寸的令价与张价
- 常用克重快捷选择，可增删，自动保存
- 分切结果按 A / B / K 系列分组，支持 20 / 30 / 50 / 70 张或自定义张数
- 可添加自定义规格，结果存本地

## 公式

令价 = 吨价 × 克重 ÷ 系数
张价 = 令价 ÷ 500

大度：889 × 1194，系数 1884
正度：787 × 1092，系数 2327
自定义：长 × 宽，系数 = 2000 ÷ 面积(m²)

## 运行

1. 微信开发者工具 → 新建项目 → 小程序
2. 目录选本项目根目录，AppID 用测试号，不用云服务
3. 编译即可
